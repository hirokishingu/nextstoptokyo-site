# nextstoptokyo-site

iPhone 用のゲーム「つぎは東京」（英語 Next Stop Tokyo）の公開ページ。App Store Connect の「サポート URL」と「プライバシーポリシー URL」に入れるもの。アプリの中のサポート・プライバシーのリンクも同じ場所を指す。

| ページ | 役割 |
|---|---|
| `index.html` | サポート・購入の復元・お問い合わせ（日本語・英語） |
| `privacy.html` | プライバシーポリシー（日本語・英語）。アプリの中の説明と食い違わせない |
| `credits.html` | 地理データ・クレジット（Project PLATEAU、国土地理院、OpenStreetMap）とフォントのライセンス |
| `noto-license.txt` | Noto Sans CJK JP のライセンス（SIL OFL 1.1） |
| `data/next-stop-tokyo-osm-data.zip` | ゲームで使っている、OpenStreetMap のデータを加工したデータ（ODbL 1.0）と加工の方法 |

公開：GitHub Pages（`main` の直下）。
